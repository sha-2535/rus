# رزومه یار (ResumeYar) — دستیار هوشمند کاریابی و رزومه‌ساز مبتنی بر هوش مصنوعی

«رزومه یار» یک پلتفرم نسل جدید برای کارجویان است که با ترکیب هوش مصنوعی، تحلیل برداری و اصول طراحی پیشرفته (Material Design 3 + Glassmorphism)، فرایند جستجوی شغل و ارسال رزومه را دگرگون می‌کند.

---

## 🌟 ویژگی‌های کلیدی

1. **طراحی مدرن Glassmorphism و Material Design 3:**
   - کارت‌های شیشه‌ای مات با افکت `backdrop-blur-xl` و حاشیه‌های ظریف نیمه‌شفاف.
   - پشتیبانی کامل از تم‌های روشن (Light) و تاریک (Dark) با قابلیت ذخیره‌سازی در حافظه محلی.
   - گرادیان رنگی شاخص (Indigo → Violet → Fuchsia) برای دکمه‌های اصلی و حلقه‌های امتیازدهی.

2. **پشتیبانی کامل از زبان فارسی و راست‌چین (RTL):**
   - قلم استاندارد **وزیرمتن (Vazirmatn)**.
   - ساختار کاملاً راست‌به‌چپ با تایپوگرافی خوانا و استانداردهای دسترسی‌پذیری WCAG AA.

3. **حلقهٔ استدلال زنده ایجنت هوشمند (Agentic Activity Panel):**
   - کشوی تعاملی فعالیت‌های زنده ایجنت برای مشاهده زنجیره تفکر: استخراج پروفایل، تحلیل ملزومات آگهی، محاسبه درصد انطباق و ساخت رزومه اختصاصی.

4. **تحلیل عمیق و محاسبه نمره تناسب (Match Score Ring):**
   - حلقه امتیازدهی از ۰ تا ۱۰۰ با کد رنگی هوشمند (قرمز <۵۰، زرد ۵۰–۷۵، سبز >۷۵).
   - تحلیل نقاط قوت، شکاف‌های دانشی و پاسخ شفاف به سوال «چرا این نمره؟».

5. **شخصی‌سازی خودکار رزومه و کاور لتر (Tailor Resume):**
   - نمایش دوطرفه مقایسه‌ای (Split View) رزومه اصلی در برابر رزومه سفارشی.
   - تزریق خودکار کلیدواژه‌های طلایی منطبق بر سیستم‌های ATS کارفرمایان.
   - امکان ارائه بازخورد زنده متنی (مانند «پروژه‌ها را پررنگ‌تر کن») و بازنویسی فوری توسط ایجنت.
   - امکان دانلود فایل متنی/PDF و کپی مستقیم در کلیپ‌بورد.

## 🚀 نحوه راه‌اندازی و اجرا

برای اجرای محلی پروژه، دستورات زیر را در ترمینال اجرا کنید:

```bash
# نصب وابستگی‌ها
npm install

# اجرای سرور توسعه محلی روی پورت 3000
npm run dev
```

برنامه روی آدرس `http://localhost:3000` در دسترس خواهد بود.

## 🔌 نحوه اتصال به بک‌اند FastAPI

لایه ارتباطی شبکه در فایل `src/lib/api.ts` پیاده‌سازی شده است. اندپوینت‌ها دقیقاً مطابق با استانداردهای وب و فریم‌ورک FastAPI نام‌گذاری شده‌اند:

- `POST /auth/register` : ثبت‌نام کاربر جدید
- `POST /auth/login` : ورود و دریافت توکن JWT
- `POST /resume/upload` : آپلود فایل رزومه یا متن و استخراج هوشمند موجودیت‌ها
- `POST /preferences` : ثبت اولویت‌های شغلی و بازه حقوق
- `GET /jobs` : دریافت لیست موقعیت‌های شغلی (همراه با پارامترهای جستجو و فیلتر)
- `POST /jobs/match` : اجرای ارزیابی هوشمند تناسب آگهی با بردار رزومه
- `POST /resume/tailor` : تولید رزومه اختصاصی و کاور لتر
- `POST /feedback` : ارسال بازخورد زبان طبیعی کاربر جهت بازنویسی و تولید نسخه جدید

### فعال‌سازی بک‌اند واقعی:
کافی است در فایل `.env` متغیر زیر را مقداردهی نمایید:

```env
NEXT_PUBLIC_API_URL="http://your-fastapi-backend:8000"
VITE_API_URL="http://your-fastapi-backend:8000"
```

هنگامی که این متغیر تنظیم شود، کلاینت به صورت خودکار درخواست‌ها را به جای داده‌های Mock، به سرور ارسال می‌کند و توکن احراز هویت را در سرآیند `Authorization: Bearer <TOKEN>` ضمیمه خواهد کرد.
